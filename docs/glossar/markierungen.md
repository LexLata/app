# Glossar: Markierungen

Datenmodell und Konfliktbegriffe.

## Verankerung

- Ausgangsstelle = Norm oder Überschrift, an der eine Markierung steht
- Bezugstext = Wortlaut des Textabschnitts, auf den sich eine Markierung bezieht; wird beim Anlegen der Markierung gespeichert
- Textstelle = Textpfad und Zeichenbereich des Bezugstextes in einem Element
  - Textpfad = strukturelle Position innerhalb eines Elements (Absatz, Satz, Nummer...)
- Bereich = Position einer Markierung außerhalb des Normtextes: amtlicher Titel, nichtamtlicher Titel oder Bezeichnung
- pauschale Verweismarkierung/Kommentar = hat keinen Bezugstext, sondern bezieht sich auf die gesamte Ausgangsnorm oder Ausgangsüberschrift

## Verweismarkierung

- Verweistext = der Text den der Nutzer eingibt und der angezeigt wird
- Zielnorm = konkrete Norm, auf die ein Verweis verweist
- Verweis auf ein ganzes Gesetz = Verweisziel ohne konkrete Normangabe
- Abgrenzung: ein bloßer Verweis auf "Abs. 3" wird nicht als Verweisziel erfasst

## Markierungskonflikte

- Markierungskonfliktfenster = Hilfsfenster zur Anzeige und Bearbeitung der Markierungskonflikte
- Elementstand = beim Speichern festgehaltene Vergleichsangaben zum Ausgangselement oder zur Zielnorm; dienen zur Erkennung von Markierungskonflikten
- Konfliktaktion = Vorgang zur Bearbeitung eines Markierungskonflikts (z. B. Importieren, Löschen, Verknüpfen)
- Konfliktseitenleiste = Leiste im Markierungskonfliktfenster, die zur Auswahl die möglichen Konfliktaktionen und Hilfe zeigt

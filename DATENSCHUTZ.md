# Datenschutzhinweis LexLata

Stand: November 2026

LexLata übermittelt keine Daten an die Entwickler. Die Entwickler betreiben keinen eigenen Server und erhalten keine Nutzungs- oder Abrufstatistik.

Die in LexLata gespeicherten Daten bleiben lokal auf Ihrem Gerät. Sie werden von LexLata nicht verschlüsselt.

## Internetverbindungen

LexLata verbindet sich nur zu den folgenden Zwecken mit dem Internet. Der jeweilige Empfänger erhält dabei insbesondere die IP-Adresse, den Zeitpunkt und die angeforderte Seite bzw. Ressource.

| Zweck                                                       | Empfänger                                                     |
| ----------------------------------------------------------- | ------------------------------------------------------------- |
| Import und Aktualisierung von Bundesrecht                   | `www.gesetze-im-internet.de`                                  |
| Import und Aktualisierung von Landesrecht Baden-Württemberg | `www.landesrecht-bw.de`                                       |
| Import und Aktualisierung von Europarecht                   | `publications.europa.eu` (Amt für Veröffentlichungen der EU)  |
| Aktualisierung über die Gesetze-Datenbank                   | `raw.githubusercontent.com` (GitHub)                          |
| Prüfung auf neue App-Versionen und deren Download           | `github.com`, `release-assets.githubusercontent.com` (GitHub) |

Landesrecht Baden-Württemberg lädt LexLata in einem nicht sichtbaren Browserfenster. Das entspricht dem Aufruf der Website in einem Browser, jedoch ohne dauerhafte Speicherung von Cookies. Welche Daten die Website dabei selbst oder über eingebundene Dienste erhebt, bestimmt ihr Betreiber.

GitHub (GitHub, Inc., USA) kann Abrufe protokollieren; dabei kann eine Übermittlung in die USA stattfinden. Die Entwickler erhalten diese Protokolle nicht; sie sehen höchstens die von GitHub angezeigte Zahl der Downloads von Programmdateien.

## Automatische Prüfungen

- App-Updates: beim Start und täglich, nach einer fehlgeschlagenen Prüfung stündlich. Abschaltbar unter _Einstellungen → Allgemein → Automatisch nach Updates suchen_.
- Gesetze (Bund, Land BW, EU): wöchentlich. Abschaltbar unter _Einstellungen → Werkzeuge → Gesetze automatisch aktualisieren → Nie_.
- Gesetze-Datenbank: standardmäßig aktiv. Abschaltbar unter _Einstellungen → Erweitert_. Dann lädt LexLata direkt von den Originalquellen.
